# DX12-Rasterization-vs-Ray-Tracing

A DirectX 12 rendering project comparing rasterization and ray tracing techniques through lighting, shadow, and reflection experiments.

## Overview

This project was developed as a graduation project to investigate the visual and technical differences between rasterization and ray tracing in DirectX 12.

The renderer provides a controlled environment for comparing rendering techniques under identical scene conditions, focusing on lighting models, shadow generation, and reflection rendering.

## Features

* Rasterization and Ray Tracing comparison
* Shadow Map vs Shadow Ray experiments
* Reflection rendering comparison
* Lighting model improvements
* Dynamic lighting test scenes
* FlightHelmet glTF model integration

## Project Goals

* Compare rasterization and ray tracing under identical scenes
* Analyze visual differences in shadows and reflections
* Evaluate rendering techniques for real-time graphics applications
* Build a practical DirectX 12 and DXR rendering framework

## Technologies

* C++
* DirectX 12
* DirectX Raytracing (DXR)
* HLSL
